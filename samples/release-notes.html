Release notes

What changed in each release of the product, grouped by impact: new features, improvements, and bug fixes. The current release is listed first. This page is an illustrative sample — release notes for a web-based task and workspace management application.

Version 2.2.0 Current release

Released October 10, 2025

Version 2.2.0 focuses on faster collaboration and smarter search. Teams that share workspaces can now work in the same task list at the same time, and search returns precise, highlightable results that are easy to re-run later.

What's new

  • Real-time collaboration for shared tasks. Multiple users can now simultaneously view, edit, and comment on tasks within a shared workspace. Changes are synced instantly, and presence indicators show who is active — improving team productivity and transparency.

Improvements

  • Upgraded search. You can now apply advanced filters, view highlighted keywords in results, and save custom search presets for repeated use. These improvements make it easier to locate specific tasks, documents, or users quickly and accurately.

Bug fixes

  • Push notifications on iOS. A critical issue that caused missed alerts due to background refresh limitations has been resolved. Notifications are now delivered reliably across all supported platforms, ensuring timely updates and reminders.
Update to this version

Most users update automatically. If automatic updates are turned off, download the latest version from the product page. Release notes for versions older than 2.0.0 are available in the help center archive.

Version 2.1.0

Released September 15, 2025

What's new

  • Attach files to new tasks. You can now upload files directly during task creation. This enables better context sharing by attaching relevant documents, images, or reference materials to tasks, streamlining collaboration and reducing the need for external file sharing.
  • Multi-factor authentication (MFA) on sign-in. An extra layer of security is now available: verify your identity through a secondary method, such as a mobile app or SMS code, to protect your account from unauthorized access.

Improvements

  • Faster dashboard. Dashboard performance has been optimized to reduce refresh latency. You will notice quicker load times and smoother transitions when navigating between widgets and data views, especially on lower-bandwidth connections.

Bug fixes

  • Resolved login errors that affected mobile users on both Android and iOS. The authentication flow has been stabilized, and error handling improved for a seamless sign-in experience.

Version 2.0.0

Released August 1, 2025 — major release

View the 2.0.0 release notes

What's new

  • Redesigned user interface. A complete redesign of the user interface was launched, focusing on clarity, accessibility, and modern aesthetics. The new layout improves visual hierarchy, simplifies navigation, and adheres to accessibility standards for users with visual or motor impairments.

Improvements

  • Streamlined navigation. The navigation menu has been streamlined to reduce clutter and improve usability. Frequently accessed modules are now grouped logically, and collapsible sections let you customize your workspace for faster access to essential tools.

Bug fixes

  • Resolved login errors affecting mobile users on Android and iOS platforms.
  • Stabilized the authentication flow and improved error handling across devices.
